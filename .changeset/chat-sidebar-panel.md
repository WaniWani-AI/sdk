Open the chat in a sidebar. Set `data-panel-layout="sidebar"` (or `panelLayout: "sidebar"` in `WaniWani.chat.init()`) with `data-mode="floating"` or `data-mode="composer"`, and a send from the bar or the box slides a full-height panel in from the right edge of the page. The default stays `modal`. Set the width with `--ww-sidebar-width` (default `440px`). Phones still get the full-screen sheet.
